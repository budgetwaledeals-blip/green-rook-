# green-rook-
Green Rook is a chess-rook-themed antivirus for Windows and Linux. It blocks malware, ransomware and scam links, monitors suspicious behavior, backs up your files and quarantines threats safely. Its quiet mode never interrupts your work.

   TO USE IT- 
   
  Download the greenrookv3.14 zip file 
  extract it 
  Open and run install
